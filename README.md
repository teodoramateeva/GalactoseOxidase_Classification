#### **Description**

This module reads the extracted, averaged features from the Molecualar Dynamics (MD) simulation and select the top features. It then uses those features to fit a Random Forest Model to classify variants of Galactose Oxidase, based on whether the variant is predicted to slow down or enhance the rate for the catalytic conversion of the alcohol.


#### **Example call**

```bash
python __main__.py -i path/to/your/input.csv
```
